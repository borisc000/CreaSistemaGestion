Estado actual del MVP

    Readiness para Firebase

      Modelo sugerido en Firestore

      Colecciones base

      • tenants/{tenantId}/tenders
      • tenants/{tenantId}/contracts
      • tenants/{tenantId}/operationTasks
      • tenants/{tenantId}/financeEntries
      • tenants/{tenantId}/vacancies
      • tenants/{tenantId}/candidates
      • tenants/{tenantId}/peopleRecords
      • tenants/{tenantId}/personDocuments

      Seguridad recomendada

      • Auth obligatorio y roles por custom claims.
      • Reglas por tenantId y permiso de modulo.
      • Audit logs en Cloud Functions por escritura.
      • Soft delete para trazabilidad.

      Backlog antes de conectar

      • Definir catalogos fijos (estados, categorias).
      • Normalizar IDs y llaves de relacion.
      • Agregar validaciones de negocio por formulario.
      • Preparar capa de repositorio para switchear storage.
